## 3. 整体架构

### 3.1 分层架构

```
┌─────────────────────────────────────────────────────────┐
│                    表现层 (qEmbyApp)                      │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐   │
│  │  Views   │ │Components│ │ Managers │ │  Utils   │   │
│  └────┬─────┘ └────┬─────┘ └────┬─────┘ └────┬─────┘   │
│       └─────────────┴────────────┴────────────┘         │
│                          │                               │
├──────────────────────────┼───────────────────────────────┤
│                    核心层 (qEmbyCore)                     │
│                          │                               │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐   │
│  │ Services │ │  Models  │ │   API    │ │  Config  │   │
│  └────┬─────┘ └──────────┘ └────┬─────┘ └──────────┘   │
│       │                         │                         │
│       └─────────┬───────────────┘                         │
│                 │                                         │
│  ┌──────────────┴──────────────┐                         │
│  │       QEmbyCore (门面)      │                         │
│  └──────────────┬──────────────┘                         │
└─────────────────┼───────────────────────────────────────┘
                  │
                  ▼
┌─────────────────────────────────────────────────────────┐
│                    外部服务                               │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐                 │
│  │Emby/Jelly│ │ DandanPlay│ │   MPV    │                 │
│  │   Server │ │  弹幕服务  │ │ 播放引擎  │                 │
│  └──────────┘ └──────────┘ └──────────┘                 │
└─────────────────────────────────────────────────────────┘
```

### 3.2 核心设计模式

1. **Facade 模式**: `QEmbyCore` 是核心库的门面类，持有所有 Service 实例
2. **Service 模式**: 按功能域划分 Service（Auth、Media、Admin、Danmaku）
3. **信号-槽路由**: View 通过信号发射导航请求，HomeView 接收并创建对应页面
4. **工厂方法**: HomeView 中的 `createXxxView()` 方法按需创建动态页面
5. **协程异步**: 所有网络调用使用 QCoro C++20 协程 (`QCoro::Task<T>`)

### 3.3 数据流

```
用户操作 → View (UI事件)
         → BaseView (通用处理: 播放/收藏/菜单等)
         → QEmbyCore::xxxService() (业务逻辑)
         → Service 调用 ApiClient (HTTP请求)
         → NetworkManager (底层网络)
         → Emby/Jellyfin REST API
```

## 5. 构建配置要点

### 根 CMakeLists.txt
- 项目: qEmby v0.0.3, C++20 必需
- 自动 MOC/UIC/RCC
- FetchContent: QCoro 0.10.0, spdlog 1.15.3
- 子目录: `libs/qwindowkit`, `src/qEmbyCore`, `src/qEmbyApp`

### qEmbyCore (共享库)
- 链接: Qt Gui, Core, Network, Concurrent, WebSockets, QCoro6::Core, QCoro6::Network
- 导出宏: `QEMBYCORE_LIBRARY`

### qEmbyApp (可执行文件)
- 链接: Qt Gui, Widgets, OpenGLWidgets, qEmbyCore, QWKWidgets, WidgetFrame, QCoro6, spdlog
- 平台特定: macOS (CoreFoundation/IOKit), Linux (可选 Qt DBus), Windows (windeployqt)
- 国际化: Qt 翻译系统, `qEmby_zh_CN.ts`
- macOS Bundle ID: `com.hl.qEmby`

## 6. 三个独立的 QNetworkAccessManager 实例

| 实例 | 位置 | 用途 |
|------|------|------|
| `NetworkManager::m_networkManager` | `qEmbyCore/api/networkmanager.cpp` | 通用 API 请求 (JSON, 文本, 字节) |
| `MediaService::m_imageManager` | `qEmbyCore/services/media/mediaservice.cpp` | 图片获取 (500MB 磁盘缓存) |
| `DownloadManager::m_networkManager` | `qEmbyApp/managers/downloadmanager.cpp` | 文件下载 (支持暂停/恢复) |
