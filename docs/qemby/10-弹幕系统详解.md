## 2. 弹幕加载流程

### 2.1 自动加载流程

```
PlayerView::playMedia() 开始播放
         │
         ▼
检查 ConfigKeys::DanmakuAutoLoad == true ?
         │
         ▼ YES
构造 DanmakuMediaContext:
  {
    serverId, mediaId, mediaSourceId,
    itemType, title, originalTitle,
    seriesName, productionYear,
    seasonNumber, episodeNumber,
    durationMs, path, providerIds
  }
         │
         ▼
DanmakuService::prepareDanmaku(context)
         │
         ▼
检查 ConfigKeys::DanmakuAutoMatch == true ?
         │
    ┌────┴────┐
    YES       NO
    │         │
    ▼         ▼
resolveMatch()   needManualMatch() = true
    │         │
    ▼         │
searchCandidates()  → 搜索匹配候选
    │         │
    ▼         │
按标题/年份/集数评分排序   │
    │         │
    ▼         │
选择最佳匹配 (score > 阈值)
    │         │
    ▼         │
获取弹幕数据     显示手动匹配对话框
    │              PlayerDanmakuIdentifyDialog
    │              → 用户选择匹配项
    │              → prepareDanmakuForCandidate()
    │                    │
    └────────────────────┘
         │
         ▼
DanmakuLoadResult
  ├── success=true
  │   ├── hasComments() → 加载到 NativeDanmakuOverlay
  │   └── hasRenderableTrack() → 加载 ASS 文件到 MPV
  │
  └── success=false
      └── needManualMatch=true → 显示手动匹配按钮
```

```
  └── GET /api/v2/search/anime?keyword=... → 搜索动漫

         ▼

  │                                          │
  │ ┌──────────────────────────────────────┐ │

  │ ├──────────────────────────────────────┤ │
  │ │ 候选2: 进击的巨人 S01E02               │ │
  │ │        弹幕数: 1876  匹配度: ★★★★      │ │
  │ ├──────────────────────────────────────┤ │
  │ │ 候选3: ...                            │ │
  │ └──────────────────────────────────────┘ │
  └──────────────────────────────────────────┘
         │
         ▼

         │
         ▼

```

## 3. 弹幕渲染

### 3.1 原生渲染 (NativeDanmakuOverlay)

```
渲染方式: QPainter 直接绘制在透明 Widget 上
位于: 视频画面正上方 (z-order)

弹幕类型:
  mode=1: 滚动弹幕 (从右到左)
  mode=4: 底部弹幕 (固定在底部)
  mode=5: 顶部弹幕 (固定在顶部)

弹幕生命周期:
  1. 创建: 根据 timeMs 在正确时间点创建
  2. 滚动: 每帧更新 x 坐标 (滚动弹幕)
  3. 固定: 显示 durationMs 毫秒后消失 (顶部/底部)
  4. 回收: 移出屏幕或超时后回收

每帧更新:
  positionChanged(currentPosition) → DanmakuController
    → 遍历 comments, 筛选当前时间范围内的弹幕
    → 推送到 NativeDanmakuOverlay
    → overlay.update() → paintEvent()
    → QPainter 绘制每条弹幕

弹幕样式:
  颜色: comment.color (RGB 整数 → QColor)
  字体: 字号 = baseSize * fontScale
  描边: outlineSize 像素
  阴影: shadowOffset 像素
  透明度: opacity (0.0 - 1.0)

密度控制:
  density > 0 时限制同屏弹幕数量
  超出时随机丢弃

区域控制:
  areaPercent (0.0 - 1.0)
  控制弹幕只在上 areaPercent% 的区域显示
```

### 3.2 ASS 字幕渲染

```
渲染方式: DanmakuAssComposer 生成 ASS 字幕文件 → MPV 加载

流程:
  1. DanmakuComment 列表 → DanmakuAssComposer
  2. 生成 ASS 文件:
     - 文件头 (分辨率, 字体, 样式)
     - 每条弹幕一个 Dialogue 行
     - 滚动弹幕: \move(x1,y1,x2,y2) 效果
     - 顶部/底部弹幕: \an8/\an2 定位
  3. 保存到临时文件
  4. MPV 加载: mpvController.command(["sub-add", assPath])
  5. DanmakuLoadResult.assFilePath 保存路径

优势:
  - 由 MPV 渲染, 性能更好
  - 支持更多 ASS 效果

劣势:
  - 不能动态调整 (需重新生成)
  - 与正文字幕冲突 (需要双字幕支持)
```

## 4. 弹幕缓存

### 4.1 匹配结果缓存

```
DanmakuCacheStore:
  存储位置: <AppDataLocation>/danmaku/{serverId}/
  缓存内容: 匹配关系 + 弹幕数据

缓存键:
  DanmakuMediaContext.cacheKey()
  → "{serverId}_{mediaId}_{mediaSourceId}"

缓存有效期:
  ConfigKeys::DanmakuCacheHours (默认 720 小时 = 30 天)

缓存操作:
  - 命中缓存 → 直接返回弹幕, 不再请求 API
  - 过期 → 重新获取
  - 手动清除: DanmakuService::clearCache()
```

### 4.2 手动匹配持久化

```
saveManualMatch(context, candidate):
  将用户选择的手动匹配关系持久化
  下次播放同一集时:
    1. 检查手动匹配 → 有则直接使用
    2. 没有则走自动匹配流程

存储位置: <AppDataLocation>/danmaku/{serverId}/matches.json
```

## 6. DandanPlay API 详解

### 6.1 匹配接口

```
POST /api/v2/match
Content-Type: application/json

Body:
{
  "fileName": "Attack.on.Titan.S01E01.mkv",
  "fileHash": "ed2khash...",
  "fileSize": 1234567890,
  "videoDuration": 1416000,  // 毫秒
  "matchMode": "hashAndFileName"
}

返回:
{
  "matches": [
    {
      "episodeId": "1234567",
      "animeTitle": "进击的巨人",
      "episodeTitle": "二千年后的君",
      "season": 1,
      "episode": 1,
      "shift": 0
    }
  ]
}
```

### 6.2 搜索接口

```
GET /api/v2/search/episodes?keyword=进击的巨人
GET /api/v2/search/anime?keyword=进击的巨人

返回:
{
  "animes": [
    {
      "animeId": 12345,
      "animeTitle": "进击的巨人",
      "episodes": [
        {
          "episodeId": 1234567,
          "episodeTitle": "第1话 二千年后的君"
        }
      ]
    }
  ]
}
```

### 6.3 弹幕获取接口

```
GET /api/v2/comment/{episodeId}
Headers:
  Accept: application/json

返回:
{
  "comments": [
    {
      "cid": 123456,
      "p": "12.3,1,16777215,timestamp,userId",
      // 格式: "时间,模式,颜色,时间戳,用户ID"
      "m": "弹幕内容"
    }
  ]
}
```

## 7. 弹幕颜色系统

```
颜色格式: RGB 整数
  16777215 = 0xFFFFFF = 白色
  255      = 0x0000FF = 蓝色
  16711680 = 0xFF0000 = 红色
  65280    = 0x00FF00 = 绿色

转换:
  QColor = QColor(color >> 16 & 0xFF, color >> 8 & 0xFF, color & 0xFF)
```

## 8. 弹幕选项滑块组件 (DanmakuOptionSlider)

```
每个弹幕设置项对应的滑块组件:

属性:
  - label: 设置项名称
  - min/max: 范围
  - step: 步长
  - value: 当前值
  - formatValue(value): 格式化显示

样式:
  - 深色/浅色主题适配
  - 滑块轨道 + 填充色
  - 悬停提示
```
