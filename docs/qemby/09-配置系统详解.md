# 配置系统详解

## 1. ConfigStore (配置存储)

**文件**: `src/qEmbyCore/config/configstore.h`

### 1.1 核心设计

```
单例模式, 线程安全:
  - 后端: QSettings (INI 格式)
  - 缓存: QHash<QString, QVariant> (内存缓存)
  - 线程安全: QMutex

存储位置:
  - QStandardPaths::AppDataLocation
  - 文件名: qEmby.ini

初始化:
  ConfigStore::instance() → 首次访问时创建
  自动加载 INI 文件

读写接口:
  getValue(key) → QVariant        (缓存优先)
  setValue(key, value)            (写缓存 + 写 INI)
  remove(key)                    (删缓存 + 删 INI)
  contains(key) → bool
```

### 1.2 键名构建函数

```
// 全局配置
"general/language" → 直接使用

// 服务器级配置
forServer(serverId, baseKey)
→ "server/{serverId}/{baseKey}"
例: "server/uuid-123/player/volume_level"

// 媒体库级配置
forLibrary(serverId, libraryId, baseKey)
→ "server/{serverId}/library/{libraryId}/{baseKey}"
例: "server/uuid-123/library/movies/sort/index"

// 分类级配置
forCategory(serverId, categoryId, baseKey)
→ "server/{serverId}/category/{categoryId}/{baseKey}"
```

## 3. SettingsCard 自动绑定

```
SettingsCard 组件可以自动绑定到 ConfigStore:

SettingsCard* card = new SettingsCard();
card->setConfigKey(ConfigKeys::PlayerHwDec);
card->setTitle("硬件解码");
card->setDescription("使用 GPU 加速视频解码");
card->setControl(new ModernComboBox({"auto", "no", "auto-copy"}));

// 自动读取和保存配置
// 读取: ConfigStore::instance()->getValue(key)
// 保存: ConfigStore::instance()->setValue(key, newValue)
```

## 4. 推荐缓存

```
MediaService::RecommendCache:

内存缓存:
  QList<MediaItem> items
  QDateTime fetchTime
  QString userId
  QString serverId

磁盘缓存:
  路径: <AppDataLocation>/recommend_cache_{serverId}.json
  自动保存/加载

有效期:
  默认 24 小时
  可通过 ConfigKeys::DataCacheDuration 配置

清除:
  MediaService::clearRecommendCache()       → 全部清除
  MediaService::removeRecommendCacheItem()  → 删除单项
```
