## 2. 登录 ↔ 主页切换

```
┌──────────┐     loginCompleted()     ┌──────────┐
│          │ ────────────────────────▶ │          │
│ LoginView│                           │ HomeView │
│          │ ◀──────────────────────── │          │
└──────────┘     logoutRequested()    └──────────┘

切换动画:
  登录→主页:
    1. 淡出 LoginView (120ms)
    2. 窗口放大 450x320 → 1280x800 (350-500ms, InOutCubic)
    3. 淡入 HomeView (250ms, OutQuad)

  主页→登录:
    1. 淡出 HomeView (120ms)
    2. 窗口缩小 1280x800 → 450x320
    3. 淡入 LoginView
```

## 3. HomeView 内部导航栈

```
HomeView 维护一个导航栈:
  QStack<RouteInfo> m_navStack

RouteInfo 结构:
  {
    QPointer<QWidget> widget;   // 页面组件
    bool isDynamic;              // 是否动态创建 (可被销毁)
    QString routeType;           // 路由类型: "dashboard", "favorites",
                                 //          "detail", "library", "player"...
    QString routeId;             // 路由 ID (如 itemId)
    QString routeTitle;          // 路由标题
    QString routeExtraId;        // 额外 ID
  }

持久页面 (isDynamic=false):
  - DashboardView
  - FavoritesView

动态页面 (isDynamic=true, 返回时销毁):
  - DetailView
  - LibraryView
  - CategoryView
  - SeasonView
  - SearchView
  - PlayerView
  - SettingsView
  - ManageView
```

## 5. 每个页面的导航信号连接

### 5.1 DashboardView

```
用户操作                    发射的信号                     目标页面
────────────────────────────────────────────────────────────────────
点击媒体卡片                navigateToDetail(itemId, name)  → DetailView
点击媒体库磁贴              navigateToLibrary(libId, name)  → LibraryView
点击 "继续观看" 全部         navigateToLibrary(libId, name)  → LibraryView
点击 "最新" 全部            navigateToLibrary(libId, name)  → LibraryView
```

**HomeView 连接代码 (伪代码)**:
```cpp
auto* view = new DashboardView(m_core);
connect(view, &DashboardView::navigateToDetail,
        this, [this](auto id, auto name) {
    pushView(createDetailView(id, name));
});
connect(view, &DashboardView::navigateToLibrary,
        this, [this](auto id, auto name) {
    pushView(createLibraryView(id, name));
});
```

## 6. 典型用户流程

### 6.1 浏览并播放电影

```
DashboardView
  │ 看到推荐电影
  │ 点击海报
  ▼
DetailView (电影详情)
  │ 看到简介、评分、演员
  │ 点击 ▶ 播放
  ▼
PlayerView (播放)
  │ 观看中...
  │ 按 ESC 或点击返回
  ▼
DetailView (返回详情)
  │ 点击返回
  ▼
DashboardView (返回首页)
```

### 6.2 追剧流程

```
DashboardView
  │ 看到 "继续观看" 的剧集
  │ 点击海报
  ▼
DetailView (剧集详情)
  │ 看到季列表、集列表
  │ 点击当前季的下一集
  ▼
DetailView (集详情) 或直接
  │ 点击 ▶ 播放
  ▼
PlayerView (播放集)
  │ 播放完毕
  │ 自动推荐下一集 (右侧面板)
  │ 点击下一集
  ▼
PlayerView (继续播放下一集)
  │ 按 ESC
  ▼
DetailView (返回剧集详情)
```

### 6.3 搜索流程

```
顶部搜索框
  │ 输入关键词
  │ 按 Enter
  ▼
SearchView (搜索结果)
  │ 切换标签: 全部/电影/剧集/合集/人物
  │ 点击结果
  ▼
DetailView (详情)
```

### 6.4 按分类浏览

```
DetailView (电影详情)
  │ 看到类型标签: [科幻] [动作]
  │ 点击 [科幻]
  ▼
LibraryView (FilteredMode, genreFilter="科幻")
  │ 看到所有科幻电影
  │ 点击电影
  ▼
DetailView (详情)
```

### 6.5 管理员操作

```
HomeView 侧边栏
  │ 点击 🛠 管理 (仅管理员可见)
  ▼
ManageView
  │ 查看仪表盘/用户/媒体库/任务/日志/转码
  │ 管理操作 (CRUD)
  │ 点击返回
  ▼
HomeView (返回)
```

## 7. 导航动画

```
前进 (pushView):
  当前页面向左滑出 ──▶ 新页面从右滑入
  时长: 350ms
  缓动: OutCubic
  方向: LeftToRight

后退 (navigateBack):
  当前页面向右滑出 ◀── 上一页从左滑入
  时长: 350ms
  缓动: OutCubic
  方向: RightToLeft

重置 (resetToView):
  直接切换 (无动画) 到 DashboardView / FavoritesView
  清空导航栈中所有动态页面

快照模式 (可选):
  截取离场页面截图作为过渡
  避免复杂的重新布局
  通过 ConfigKeys::SnapshotNavigation 配置
  可通过 ConfigKeys::UiAnimations 全局禁用动画
```

## 10. 右键菜单操作 (所有 BaseView 子类通用)

```
在任意媒体卡片上右键:
┌────────────────────────┐
│ ▶ 播放                  │  → handlePlayRequested()
│ ▶ 外部播放器 ▶          │  → executeExternalPlay()
│   ├─ mpv               │
│   └─ VLC               │
│────────────────────────│
│ ❤ 添加收藏 / 取消收藏    │  → handleFavoriteRequested()
│ ✔ 标记已播放            │  → handleMarkPlayedRequested()
│ ✘ 标记未播放            │  → handleMarkUnplayedRequested()
│ 🚫 从继续观看移除        │  → handleRemoveFromResumeRequested()
│────────────────────────│
│ 📋 添加到播放列表 ▶      │  → handleAddToPlaylistRequested()
│ 🗑 从播放列表移除        │  → handleRemoveFromPlaylistRequested()
│    (仅播放列表内项目)     │
│────────────────────────│
│ ✏ 编辑元数据            │  → handleEditMetadataRequested()
│ 🖼 编辑图片             │  → handleEditImagesRequested()
│ 🔍 识别                 │  → handleIdentifyRequested()
│ 🔄 刷新元数据            │  → handleRefreshMetadataRequested()
│────────────────────────│
│ 📥 下载                 │  → handleDownloadRequested()
│ 🗑 删除媒体             │  → handleRemoveMediaRequested()
│    (仅管理员)            │
└────────────────────────┘

管理员才能看到:
- 删除媒体
- 编辑元数据
- 编辑图片
- 识别
- 刷新元数据
```
