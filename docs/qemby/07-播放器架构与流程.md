## 2. 播放触发流程

### 2.1 点击播放按钮

```
用户点击 ▶ 播放
         │
         ▼
BaseView::handlePlayRequested(item)
         │
         ▼
BaseView::executePlay(item)
         │
         ▼
BaseView::resolvePlaybackItem(item)
  │  调用 MediaService::getItemDetail(itemId)
  │  获取完整 MediaItem (含 mediaSources)
  │  如果 item.mediaSources 非空 → 直接使用
  │  如果为空 → 调用 MediaService::getPlaybackInfo(itemId)
  │            获取 PlaybackInfo (含 mediaSources)
  │
  ▼  返回 enriched MediaItem
         │
         ▼
PlaybackManager::startPlayback()
  │  解析 MediaSourceInfo
  │  获取首选媒体源 (根据用户设置选择版本)
  │  构造 streamUrl = MediaService::getStreamUrl()
  │
  │  特殊处理:
  │  - STRM 文件: 直接返回 STRM 文件中记录的 URL
  │  - 多版本: 根据用户偏好选择 (ConfigKeys::PlayerPreferredVersion)
  │
  ▼
emit requestEmbeddedPlay(mediaId, title, streamUrl, startTicks, extraData)
         │
         ▼
HomeView 接收信号 → createPlayerView()
         │
         ▼
PlayerView::playMedia()
```

### 2.2 外部播放器

```
用户点击外部播放器按钮 (SplitPlayerButton)
         │
         ▼
BaseView::executeExternalPlay(item, playerPath)
         │
         ▼
PlaybackManager::startExternalPlayback()
         │
         ├── 检测播放器类型 (mpv, VLC, MPC)
         │
         ├── 构建命令行参数:
         │   mpv:  mpv --start={seconds} --aid={audioIdx} --sid={subIdx} {url}
         │   VLC:  vlc --start-time={seconds} --audio-track={idx} --sub-track={idx} {url}
         │   MPC:  mpc-hc64 {url} /startpos {ms} /audio {idx} /sub {idx}
         │
         ├── 启动 QProcess
         │
         └── 建立 ExternalPlayerIPC (命名管道/Socket)
             用于: 进度上报、播放控制

ExternalPlayerIPC 端点:
  mpv:  \\.\pipe\mpv_ipc_{random}  (Windows) 或 /tmp/mpv_ipc_{random}
  VLC:  TCP socket
  MPC:  WM_COPYDATA (Windows)
```

## 3. PlayerView 播放生命周期

### 3.1 初始化播放

```
PlayerView::playMedia(mediaId, title, streamUrl, startTicks, extraData)
  │
  ├── 1. 保存播放状态
  │   m_currentMediaId = mediaId
  │   m_originalStreamUrl = streamUrl
  │   m_currentPosition = 0
  │   m_isPlaying = false
  │   m_isBuffering = true
  │
  ├── 2. 恢复用户偏好
  │   音量: ConfigKeys::PlayerVolumeLevel
  │   静音: ConfigKeys::PlayerVolumeMuted
  │   缩放: ConfigKeys::PlayerDefaultScale
  │
  ├── 3. 配置 MPV
  │   hw_dec: ConfigKeys::PlayerHwDec (auto/no/auto-copy/d3d11va/vdpau)
  │   vo: ConfigKeys::PlayerVo (libmpv/gpu)
  │   video-sync: ConfigKeys::PlayerVideoSync
  │   audio-lang: ConfigKeys::PlayerAudioLang
  │   sub-lang: ConfigKeys::PlayerSubLang
  │
  ├── 4. 加载文件
  │   mpvController.command(["loadfile", streamUrl])
  │   如果 startTicks > 0:
  │     mpvController.setProperty("start", ticksToSeconds(startTicks))
  │
  ├── 5. 报告播放开始
  │   MediaService::reportPlaybackStart()
  │   保存 playSessionId
  │
  ├── 6. 加载弹幕
  │   DanmakuService::prepareDanmaku(context)
  │   如果成功 → 加载到 NativeDanmakuOverlay
  │
  ├── 7. 启动进度上报定时器
  │   m_reportTimer (10秒间隔)
  │
  └── 8. 预加载选集数据 (如果是剧集)
      获取季列表和集列表 → 缓存到 m_switcherCacheXxx
```

### 3.2 播放中

```
MPV 事件 → MpvController 信号 → PlayerView 处理:

propertyChanged("pause"):
  → 更新播放/暂停按钮状态

positionChanged(position):
  → 更新进度条位置
  → 更新时间标签
  → 驱动弹幕时间轴

durationChanged(duration):
  → 更新总时长

endOfFile("stop"):
  → 自动播放下一集 (剧集模式)
  → 或显示播放完毕提示

endOfFile("error"):
  → 显示错误提示

MPV 属性观察:
  "pause"           → 暂停状态
  "time-pos"        → 当前位置 (秒)
  "duration"        → 总时长 (秒)
  "volume"          → 音量
  "mute"            → 静音
  "eof-reached"     → 播放结束
  "idle-active"     → 空闲
  "demuxer-cache-state" → 缓冲状态

进度上报 (每10秒):
  MediaService::reportPlaybackProgress(
    itemId, sourceId, positionTicks, isPaused, playSessionId
  )
```

### 3.3 停止播放

```
PlayerView::stopAndReport()
  │
  ├── 1. 报告播放停止
  │   MediaService::reportPlaybackStopped(
  │     itemId, sourceId, positionTicks, playSessionId
  │   )
  │
  ├── 2. 停止 MPV
  │   mpvController.command(["stop"])
  │
  ├── 3. 清理弹幕
  │   m_danmakuController->clear()
  │
  ├── 4. 停止定时器
  │   m_reportTimer->stop()
  │
  └── 5. 释放电源抑制
      PowerInhibitUtils::uninhibit()
```

### 3.4 切换集/电影

```
PlayerMediaSwitcherPanel → 用户选择新集/电影
         │
         ▼
PlayerView 切换流程:
  1. stopAndReport()  (上报旧项停止)
  2. 调用 resolvePlaybackItem() (获取新项信息)
  3. playMedia(newMediaId, newTitle, newStreamUrl, newPosition, newExtraData)
  4. 更新标题、弹幕等
```

## 4. HUD 控制详解

### 4.1 顶部 HUD

| 元素 | 功能 |
|------|------|
| ◀ 返回按钮 | 返回上一页 (stopAndReport + navigateBack) |
| 标题标签 | 显示当前播放标题 |
| — 最小化 | 最小化窗口 |
| □ 最大化 | 最大化/还原窗口 |
| × 关闭 | 关闭播放器 (stopAndReport + navigateBack) |
| 网络速度 | 显示当前下载速度 (KB/s 或 MB/s) |

### 4.2 底部 HUD - 进度条区域

| 元素 | 功能 |
|------|------|
| 当前时间 | mm:ss 或 hh:mm:ss |
| 进度条 (ModernSlider) | 可拖动跳转, 悬停显示预览时间 |
| 总时长 | mm:ss 或 hh:mm:ss |
| ◀◀ 快退 | 快退 ConfigKeys::PlayerSeekStep 秒 |
| ▶/⏸ 播放/暂停 | 切换播放状态 |
| ▶▶ 快进 | 快进 ConfigKeys::PlayerSeekStep 秒 |
| 音量按钮 | 点击切换静音 |
| 音量滑块 | 调节音量 0-100 |

### 4.3 底部 HUD - 操作栏

| 按钮 | 功能 | 子面板 |
|------|------|--------|
| 倍速 | 调整播放速度 | PlayerOverlayDialog (0.5x - 3.0x) |
| 选集 | 切换集/电影 | PlayerMediaSwitcherPanel (右侧抽屉) |
| 音频 | 选择音频轨道 | PlayerOverlayDialog (轨道列表) |
| 字幕 | 选择字幕轨道 | PlayerOverlayDialog + 字幕设置 |
| 弹幕 | 弹幕开关/设置 | PlayerDanmakuSettingsDialog |
| 设置 | 播放器设置 | PlayerOverlayDialog |
| 缩放 | 视频缩放模式 | 循环切换 |
| 全屏 | 全屏切换 | - |

### 4.4 HUD 自动隐藏

```
显示条件:
  - 鼠标移动
  - 鼠标在 HUD 区域内
  - 播放暂停时

隐藏条件:
  - 鼠标静止超过 3 秒
  - 视频正在播放

隐藏动画:
  m_topOpacity → 0.0 (120ms)
  m_bottomOpacity → 0.0 (120ms)
  QParallelAnimationGroup 同时执行

显示动画:
  m_topOpacity → 1.0 (100ms)
  m_bottomOpacity → 1.0 (100ms)
```

## 5. 快捷键

| 快捷键 | 功能 |
|--------|------|
| 空格 / K | 播放/暂停 |
| ← / J | 快退 seek_step 秒 |
| → / L | 快进 seek_step 秒 |
| ↑ | 音量 +5 |
| ↓ | 音量 -5 |
| F / F11 | 全屏切换 |
| Esc | 退出全屏 / 返回 |
| M | 静音切换 |
| [ | 降低倍速 |
| ] | 提高倍速 |
| Backspace | 恢复正常速度 |
| 长按 ← | 快速倍速后退 |
| 长按 → | 快速倍速前进 |
| 长按释放 | 恢复正常播放 |

### 长按行为配置

```
ConfigKeys::PlayerLongPressSeek:
  - 快进/快退倍数 (默认 4x)

ConfigKeys::PlayerLongPressMode:
  - 按住期间改变速度
  - 按住期间快进/快退

ConfigKeys::PlayerLongPressTriggerMs:
  - 长按触发延迟 (默认 500ms)

ConfigKeys::PlayerMouseEdgeLongPress:
  - 鼠标点击屏幕边缘触发长按
```

## 6. 视频缩放模式

```
循环切换 (m_videoScaleMode):

1. "auto"     → 自适应 (保持宽高比, 适应窗口)
2. "4:3"      → 强制 4:3
3. "16:9"     → 强制 16:9
4. "stretch"  → 拉伸到窗口大小
5. "crop"     → 裁剪填充

实现: mpvController.setProperty("video-aspect-override", value)
```

## 7. 音频/字幕流选择

```
播放开始后:
  1. 获取 MediaSourceInfo.mediaStreams
  2. 过滤:
     - 音频流: type == "Audio"
     - 字幕流: type == "Subtitle"
  3. 应用用户偏好:
     - 首选音频语言: ConfigKeys::PlayerAudioLang (如 "zh,chi,en")
     - 首选字幕语言: ConfigKeys::PlayerSubLang (如 "zh,chi,en")
  4. 设置 MPV:
     mpvController.command(["aid", "auto"])  → 自动选择
     mpvController.command(["aid", index])   → 指定轨道
     mpvController.command(["sid", "no"])    → 禁用字幕
     mpvController.command(["sid", index])   → 指定字幕

外部字幕加载:
  如果 isExternal && supportsExternalStream:
    mpvController.command(["sub-add", deliveryUrl])
```

## 8. 全屏模式

```
进入全屏:
  1. 保存当前窗口几何 m_originalGeometry
  2. 保存最大化状态 m_wasMaximized
  3. 隐藏窗口栏
  4. 全屏窗口
  5. MpvWidget 全屏

退出全屏:
  1. 恢复窗口栏
  2. 恢复窗口几何
  3. 如果之前最大化 → 重新最大化
```

## 9. 电源管理

```
播放开始:
  PowerInhibitUtils::inhibit("qEmby 正在播放")
  → 防止屏幕休眠/系统睡眠

播放停止:
  PowerInhibitUtils::uninhibit()
  → 恢复正常电源管理
```
