# 组件库参考

## 1. 布局组件

### 1.1 SlidingStackedWidget
**文件**: `components/slidingstackedwidget.h`

动画堆叠组件，用于页面切换。

```
特性:
  - 继承 QStackedWidget
  - 支持四个方向滑动: LeftToRight, RightToLeft, TopToBottom, BottomToRight
  - 动画: QParallelAnimationGroup + QPropertyAnimation (widget pos)
  - 默认 350ms, OutCubic 缓动
  - 快照模式: 截取离场页面截图用于过渡
  - 可通过配置全局禁用

使用场景:
  - HomeView 内容区域切换
  - SettingsView/ManageView 子页面切换
```

### 1.2 FlowLayout
**文件**: `components/flowlayout.h`

流式布局，自动换行。

```
特性:
  - 继承 QLayout
  - 子项按流排列，宽度不足自动换行
  - 支持间距配置

使用场景:
  - DetailView 标签/类型展示
  - 管理页用户卡片排列
```

### 1.3 CollapsibleSection
**文件**: `components/collapsiblesection.h`

可折叠区域。

```
特性:
  - 标题栏 + 可展开/折叠内容区

  - 动画展开/折叠

使用场景:
```

## 3. 播放器组件

### 3.1 MpvWidget
**文件**: `components/mpvwidget.h`

MPV 视频渲染 Widget。

```
特性:
  - 继承 QOpenGLWidget
  - libmpv OpenGL 渲染
  - 嵌入 MpvController

初始化流程:
  1. mpv_create()
  2. mpv_initialize()
  3. mpv_render_context_create()
  4. OpenGL 回调渲染

销毁流程:
  1. mpv_render_context_free()
  2. mpv_destroy()
```

### 3.2 MpvController
**文件**: `components/mpvcontroller.h`

MPV 控制器。

```
核心方法:
  observeProperty(property, format, id)  → 观察属性变化
  setProperty(property, value)            → 设置属性
  getProperty(property)                   → 获取属性
  command(params)                         → 执行命令

信号:
  propertyChanged(property, value)  → 属性变化通知
  positionChanged(position)         → 播放位置变化 (秒)
  durationChanged(duration)         → 时长变化 (秒)
  playbackStateChanged(isPaused)    → 播放/暂停状态
  fileLoaded()                      → 文件加载完成
  endOfFile(reason)                 → 播放结束 ("stop"/"error"/"redirect")
  errorOccurred(errorMsg)           → 错误

后台线程事件处理:
  onMpvEvents() → 在 MPV 事件线程中处理事件
  通过 Qt 信号传递到 UI 线程
```

### 3.3 NativeDanmakuOverlay
**文件**: `components/nativedanmakuoverlay.h`

原生弹幕渲染覆盖层。

```
特性:
  - 继承 QWidget, 透明背景
  - 直接在视频上方绘制弹幕
  - 支持三种弹幕模式: 滚动(1), 顶部(5), 底部(4)
  - 可配置: 透明度, 字体大小, 速度, 显示区域, 屏蔽词

弹幕渲染:
  - QPainter 绘制
  - 每帧更新弹幕位置
  - 自动回收已过期的弹幕
  - 支持颜色 (RGB 整数 → QColor)

性能优化:
  - 限制同时显示的弹幕数量 (密度控制)
  - 定时清理屏幕外弹幕
```

### 3.4 PlayerDanmakuController
**文件**: `components/playerdanmakucontroller.h`

弹幕数据/逻辑控制器。

```
职责:
  - 管理弹幕数据源
  - 根据 DanmakuRenderOptions 配置渲染参数
  - 按时间轴驱动弹幕显示
  - 处理弹幕手动匹配/搜索

与 PlayerView 交互:
  positionChanged(position) → controller.seekTo(ms)
  → 根据当前时间推送弹幕到 NativeDanmakuOverlay
```

## 8. 主题系统

```
ThemeManager:
  - 深色/浅色主题切换
  - QSS 样式表: dark-style.qss / light-style.qss
  - SVG 图标: dark/ / light/ / player/ 目录
  - 切换时发射 themeChanged() 信号
  - ThemeTransitionWidget 圆形揭示动画

样式表路径:
  :/qss/dark-style.qss
  :/qss/light-style.qss

图标路径:
  :/svg/dark/xxx.svg
  :/svg/light/xxx.svg
  :/svg/player/xxx.svg
```
