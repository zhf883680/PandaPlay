# 认证与会话管理流程

## 1. 登录流程 (AuthService::login)

```
用户输入: 服务器地址 + 用户名 + 密码
         │
         ▼
┌─────────────────────────────────────────────┐
│ Step 1: 获取服务器公开信息                     │
│ GET /System/Info/Public (无需认证)             │
│                                               │
│ 目的: 检测服务器类型 (Emby / Jellyfin)         │
│ 通过 ProductName 字段判断                       │
│                                               │
│ Emby:   ProductName = "Emby Server"           │
│ Jellyfin: ProductName = "Jellyfin Server"     │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│ Step 2: 创建临时 ApiClient                    │
│                                               │
│ - 生成新的 deviceId (UUID)                    │
│ - 创建 ServerProfile (url + type)             │
│ - 创建 ApiClient (profile + networkManager)   │
│ - 此时无 Token                                │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│ Step 3: 用户认证                              │
│ POST /Users/AuthenticateByName                │
│                                               │
│ Body: { "Username": "xxx", "Pw": "xxx" }      │
│                                               │
│ 返回:                                         │
│ {                                             │
│   "AccessToken": "xxxxxxxx",                  │
│   "User": {                                   │
│     "Id": "userId",                           │
│     "Name": "username",                       │
│     "Policy": {                               │
│       "IsAdministrator": true/false,          │
│       "EnableContentDownloading": true/false  │
│     }                                         │
│   },                                          │
│   "ServerId": "serverId"                      │
│ }                                             │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│ Step 4: 构建 ServerProfile                    │
│                                               │
│ profile.id          = UUID                    │
│ profile.url         = 服务器地址               │
│ profile.type        = Emby/Jellyfin           │
│ profile.userId      = User.Id                 │
│ profile.userName    = User.Name               │
│ profile.accessToken = AccessToken             │
│ profile.deviceId    = 生成的 deviceId          │
│ profile.isAdmin     = Policy.IsAdministrator  │
│ profile.canDownload = EnableContentDownloading│
│ profile.ignoreSslVerification = 用户选择       │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│ Step 5: 获取服务器图标                         │
│                                               │
│ Emby 路径尝试顺序:                             │
│   1. /Branding/Splash                         │
│   2. /emby/Modules/MBTail/ClientSplash        │
│                                               │
│ Jellyfin 路径:                                │
│   1. /Branding/Splash                         │
│                                               │
│ 成功后: profile.iconBase64 = base64(图片数据)   │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│ Step 6: 持久化                                │
│                                               │
│ ServerManager::addServer(profile)             │
│ → 保存到 <AppDataLocation>/servers.json       │
│                                               │
│ JSON 格式: [                                  │
│   {                                           │
│     "id": "...", "url": "...",               │
│     "userId": "...", "accessToken": "...",   │
│     ...                                       │
│   }                                           │
│ ]                                             │
└─────────────────────────────────────────────┘
         │
         ▼
    返回 ServerProfile 给 UI 层
```

## 2. 会话恢复流程 (AuthService::validateSession)

```
应用启动 / 服务器切换
         │
         ▼
┌─────────────────────────────────────────────┐
│ Step 1: 查找已保存的 Profile                  │
│                                               │
│ ServerManager::serverList() 查找 serverId     │
│ 读取 servers.json                             │
│                                               │
│ 验证: profile.isValid() → accessToken 非空    │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│ Step 2: 创建 ApiClient 并验证                 │
│                                               │
│ GET /System/Info (认证请求)                    │
│                                               │
│ 验证: 服务器可达、Token 有效                    │
│ 失败: 抛出异常，提示重新登录                    │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│ Step 3: 刷新用户信息                          │
│                                               │
│ GET /Users/{userId}                           │
│                                               │
│ 更新:                                         │
│ - profile.isAdmin (管理员状态)                 │
│ - profile.canDownload (下载权限)               │
│ - 其他策略信息                                 │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│ Step 4: 激活会话                              │
│                                               │
│ ServerManager::setActiveProfile(profile)      │
│ → 创建新的 ApiClient                          │
│ → 建立 WebSocket 连接                         │
│ → 更新 UI                                     │
└─────────────────────────────────────────────┘
```

## 3. 登出流程 (AuthService::logout)

```
用户点击登出
         │
         ▼
┌─────────────────────────────────────────────┐
│ 1. 断开 WebSocket 连接                        │
│    EmbyWebSocket::disconnect()                │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│ 2. 清除活跃会话                               │
│    ServerManager::clearActiveProfile()        │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│ 3. 发射 userLoggedOut 信号                    │
│    UI 层切换回登录页面                         │
└─────────────────────────────────────────────┘

注意: 不向服务器发送会话失效请求
Token 在服务器端仍然有效
下次启动可自动恢复
```

## 4. ApiClient 请求认证流程

每次通过 ApiClient 发送请求时的认证流程:

```
ApiClient::get/post/delete(path)
         │
         ▼
┌─────────────────────────────────────────────┐
│ 1. 拼接完整 URL                               │
│    fullUrl = profile.url + path               │
│                                               │
│ 例: https://emby.local:8096/Users/xxx/Views  │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│ 2. 构建认证头                                 │
│                                               │
│ X-Emby-Authorization:                        │
│   MediaBrowser                               │
│     Client="qEmby",                          │
│     Device="Desktop",                        │
│     DeviceId="<profile.deviceId>",           │
│     Version="0.1",                           │
│     Token="<profile.accessToken>"            │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│ 3. 构建 SSL 选项                             │
│                                               │
│ if (profile.ignoreSslVerification)            │
│   options.ignoreSslErrors = true              │
└─────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────┐
│ 4. 调用 NetworkManager 发送请求               │
│                                               │
│ NetworkManager::get(fullUrl, authHeaders)     │
│ NetworkManager::post(fullUrl, authHeaders, body) │
│ NetworkManager::deleteResource(fullUrl, authHeaders) │
└─────────────────────────────────────────────┘
```

## 5. ServerManager 生命周期管理

```
ServerManager 职责:
├── 管理服务器列表 (servers.json)
│   ├── addServer(profile)
│   ├── removeServer(serverId)
│   └── serverList() → QList<ServerProfile>
│
├── 管理活跃会话
│   ├── setActiveProfile(profile)
│   │   ├── 创建 ApiClient
│   │   └── 连接 WebSocket
│   ├── clearActiveProfile()
│   │   ├── 销毁 ApiClient
│   │   └── 断开 WebSocket
│   └── activeClient() → ApiClient*
│
└── 通知
    ├── activeServerChanged()
    └── serverListChanged()
```

## 6. UI 层登录界面交互流程

```
LoginView (登录页面)
│
├── 页面结构:
│   └── QStackedWidget (m_pageSwitcher)
│       ├── ListPage (已保存的服务器列表)
│       │   ├── ServerWheelView (服务器卡片轮播)
│       │   │   └── 每张卡片: 服务器图标 + 名称 + 地址
│       │   └── "添加服务器" 按钮
│       │
│       └── AddPage (添加新服务器)
│           ├── 协议选择 (http/https)
│           ├── 服务器地址输入
│           ├── 端口输入
│           ├── SSL 验证开关
│           ├── 用户名输入
│           ├── 密码输入
│           └── "连接" 按钮
│
├── 交互流程:
│   1. 启动 → 加载已保存服务器列表
│   2. 如有已保存服务器 → 显示 ListPage
│   3. 如无已保存服务器 → 显示 AddPage
│   4. 用户滑动选择服务器 → 自动填充地址
│   5. 点击 "连接" → 显示 LoadingOverlay
│   6. 调用 AuthService::login()
│   7. 成功 → 发射 loginCompleted()
│   8. 失败 → 显示错误提示
│
└── MainWindow 响应 loginCompleted():
    → navigateToHome()
    → 淡出 LoginView (120ms)
    → 窗口放大到 1280x800 (350-500ms, InOutCubic)
    → 淡入 HomeView (250ms)
```

## 7. 多服务器管理

```
支持多个 Emby/Jellyfin 服务器同时保存

servers.json 结构:
[
  {
    "id": "uuid-1",
    "name": "家庭服务器",
    "url": "https://emby.home.local:8096",
    "type": 0,              // Emby
    "userId": "xxx",
    "userName": "admin",
    "accessToken": "xxx",
    "deviceId": "xxx",
    "isAdmin": true,
    "canDownload": true,
    "iconBase64": "data:image/png;base64,..."
  },
  {
    "id": "uuid-2",
    "name": "Jellyfin 测试",
    "url": "http://jellyfin.test.local:8097",
    "type": 1,              // Jellyfin
    ...
  }
]

切换服务器:
1. 侧边栏点击 "退出" (登出当前)
2. 回到登录页
3. 在 ServerWheelView 中选择另一个服务器
4. 调用 validateSession(serverId) 恢复会话
```
